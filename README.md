# Memory Analysis Lab

A Next.js + MongoDB prototype for rigorous autobiographical-memory narrative analysis.

The app separates:

- Text-derived evidence
- Cognitive-psychology constructs
- Operational scores
- Interpretations
- Research hypotheses

## Run locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Create `.env.local`:

   ```bash
   cp .env.example .env.local
   ```

3. Start MongoDB and update `MONGODB_URI` if needed.

4. Start the app:

   ```bash
   npm run dev
   ```

Open `http://localhost:3000`.
